# ✈️ نظام واحة وليد لحجز الرحلات | Waleed's Oasis Flight Reservation System

مشروع برمي متكامل لإدارة وحجز رحلات الطيران بين المحافظات السورية، تم بناؤه باستخدام لغة **C++**. يركز المشروع على تقديم تجربة مستخدم سلسة عبر الشاشة السوداء (Console) مع تطبيق مفاهيم برمجية متقدمة وكتابة كود نظيف ومنظم (**Clean Code**).

## 🚀 ميزات النظام (Features)
- **عرض الرحلات المتاحة:** استعراض تفاصيل الرحلات (رقم الرحلة، الوجهة، سعر المقعد، والمقاعد المتاحة) بجدول منسق بشكل احترافي.
- **حجز الرحلات:** إمكانية تسجيل اسم المسافر، اختيار رقم الرحلة، وتحديد عدد المقاعد مع تحديث فوري للمقاعد المتبقية في الطائرة.
- **إدارة الحجوزات:** استعراض قائمة بجميع الحجوزات الحالية وتفاصيلها.
- **حساب الإحصائيات (متقدم):** حساب إجمالي المبالغ المستحقة وإجمالي عدد المقاعد المحجوزة باستخدام الخوارزميات العودية (Recursion).
- **حماية النظام (Input Validation):** حماية البرنامج من الانهيار في حال إدخال بيانات خاطئة من قبل المستخدم.

## 🛠️ التقنيات والمفاهيم المستخدمة (Technologies & Concepts)
- **اللغة الأساسية:** C++
- **هياكل البيانات (Structures):** استخدام `struct` لتمثيل بيانات الرحلات (`flight`) وبيانات الحجوزات (`rese`).
- **البرمجة العودية (Recursion):** تطبيق مفهوم الـ Recursion في دمج وحساب الإحصائيات المالية والمقاعد.
- **تنسيق الواجهة:** استخدام مكتبة `<iomanip>` لترتيب الجداول والمحاذاة، ومكتبة `<windows.h>` لإضافة الألوان وتأثيرات الكتابة المتحركة للـ Logo.
